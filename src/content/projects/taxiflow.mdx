## The problem

A notebook can demonstrate a model, but serving predictions requires repeatable preprocessing, explicit input validation, and an application that loads and exposes the trained artifact consistently.

## Implementation

As documented in my master CV, I refactored an NYC taxi ride-duration notebook into a modular Python package for data processing, feature engineering, training, and inference.

The FastAPI service includes health and metadata endpoints, single and batch predictions, Pydantic validation, startup model loading, structured JSON logs, and request correlation IDs.

## Packaging and verification

The CV records model serialization, ONNX export and parity checks, pytest tests, a multi-stage Dockerfile, non-root container execution, and Docker Compose.
