## Context

An educational social-network desktop application built with Python, PySide6, and SQLite. The project combines user profiles and posts with graph exploration, prefix search, ranked feeds, and follow recommendations.

## Architecture

- **Persistence:** SQLite stores application entities and relationships.
- **Search:** a Trie supports username-prefix lookup and autocomplete.
- **Graph analysis:** breadth-first search, adjacency matrices, centrality, and degree-of-separation calculations describe the social network.
- **Feed ranking:** popularity and time-decay signals order posts using merge sort.
- **Recommendations:** Jaccard and cosine similarity support candidate ranking; a KNN model estimates follow likelihood.
- **Presentation:** PySide6 exposes the workflows and social-graph visualization.

The team project also includes Huffman compression. Each algorithm serves a distinct purpose: a prefix match answers a direct query, whereas a similarity score or nearest-neighbor prediction estimates relevance.

## My contribution

I designed and integrated database functionality, implemented Trie-based username search, and worked on the KNN model and recommendation features. Other team members contributed graph algorithms, feed ranking, compression, messaging, visualization, and GUI integration.

## Technical considerations

The Trie and recommendation features are derived from persistent records. Username changes and relationship updates therefore require the application to keep its indexes and features consistent with SQLite data.

Jaccard similarity measures set overlap; cosine similarity compares vector direction; KNN depends on the selected features and distance metric. These methods support different retrieval and ranking decisions, rather than interchangeable measures of recommendation quality.

## Evaluation status

The repository documents the implemented features and team contributions but does not report a held-out recommendation metric or latency benchmark. The project demonstrates integration of data structures, local persistence, and recommendation logic; it does not establish production-scale performance.
