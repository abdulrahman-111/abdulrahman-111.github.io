## Context

A team-built decision-support application for FIFA Career Mode, combining match analysis, player evaluation, squad planning, and transfer analysis. Python, pandas, NumPy, and scikit-learn provide the modeling stack; dashboards and generated DOCX scouting reports present the outputs.

## Architecture

The application separates three modeling domains:

- **Match analysis:** a decision tree predicts shot outcomes; separate linear regressions estimate home and away goals, from which the winner is derived.
- **Player development:** logistic regression predicts positions, polynomial regression estimates structured game ratings, and nearest-neighbor search retrieves similar players.
- **Transfer analysis:** a logistic-regression pipeline estimates injury risk, while random forests predict goals, assists, and market value.

The datasets include StatsBomb events, EA Sports FC 24 player attributes, historical player statistics, injury records, and transfer-fee data. Their schemas and feature definitions require alignment before model outputs can be combined consistently.

## My contribution

I built the transfer-decision engine with Seif: the injury classifier, future-performance predictions, market-value model, automated scouting report, and transfer dashboards. Match simulation and player-development models belong to the wider team implementation.

## Evaluation and limitations

The repository reports these metrics. They measure different tasks and should not be compared as a single system score.

| Task                                 | Reported metric               |
| ------------------------------------ | ----------------------------- |
| Position classification              | 82.82% accuracy               |
| Structured overall-rating regression | R² = 0.9801                   |
| Injury classification                | 95.0% accuracy; 96.25% recall |
| Shot classification                  | 89.7% accuracy                |
| Match-winner prediction              | 51.7% overall accuracy        |

The high rating R² reflects structured game attributes, rather than demonstrated real-world scouting accuracy. Transfer valuation omits factors including contract length and wages. Historical injury and performance models do not account for all in-game events. The match-winner result, particularly weak draw prediction, limits its use as a forecasting tool.

## Outputs

The transfer workflow produces dashboards and a DOCX scouting report containing predictions and a recommendation score. The report is a review artifact; combining outputs does not remove each model's uncertainty or dataset limitations.
