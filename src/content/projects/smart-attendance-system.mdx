## Context

A desktop classroom-attendance prototype that processes webcam frames, runs separate face-identity, attention, and facial-expression models, and persists attendance records. The application uses OpenCV, TensorFlow, scikit-learn, PySide6, and SQLite.

## Architecture

1. **Detection:** OpenCV Haar cascades locate faces in each frame.
2. **Inference:** a custom CNN classifies attention proxies; PCA with an SVM predicts registered identities; EfficientNetB2 classifies facial expressions.
3. **Aggregation:** model outputs are associated with the student record and displayed in PySide6.
4. **Persistence:** SQLite stores timestamped records, with duplicate-attendance prevention and CSV export.

These outputs represent different classification tasks. A predicted facial expression does not establish a student's internal emotional state, and an attention label is not a direct measurement of learning or engagement.

## My contribution

I implemented emotion-recognition work and designed and integrated the database layer. The emotion path uses an ImageNet-pretrained EfficientNetB2 backbone with a four-class head for Angry, Happy, Neutral, and Sad, trained using FER-2013. Face recognition, the attention CNN, and overall GUI integration were team contributions.

## Evaluation and limitations

The repository reports the following results; they have not been independently reproduced for this portfolio.

| Task                             | Reported metric      | Evaluation context                                             |
| -------------------------------- | -------------------- | -------------------------------------------------------------- |
| Attention classification         | 95.30% test accuracy | Driver-distraction images, rather than classroom-specific data |
| Face identification              | 93.62% accuracy      | Five registered students                                       |
| Facial-expression classification | 74.4% overall F1     | Four selected FER-2013 classes                                 |

The attention dataset introduces a domain gap, and the repository notes overfitting after epoch 20. Haar detection is sensitive to face angle, lighting, and occlusion. The reported metrics do not establish performance in an unrestricted classroom deployment.

## Engineering lessons

The project connects model inference to application state: frame processing, UI updates, and committed attendance records have different responsibilities. Keeping task outputs separate makes errors easier to diagnose and avoids treating every model score as the same kind of evidence.
