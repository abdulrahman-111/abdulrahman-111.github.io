## Context

A C/Linux systems-programming project that progresses from custom command-line utilities to a small shell. The repository includes implementations of `echo`, `pwd`, `cd`, `cp`, and `mv`, followed by four shell stages.

## Implementation stages

| Stage | Documented scope                                                              |
| ----- | ----------------------------------------------------------------------------- |
| Femto | Basic external-command execution                                              |
| Pico  | Additional parsing, exit-code handling, and history                           |
| Nano  | Input, output, and error redirection                                          |
| Micro | Integrated utilities, built-ins, variable expansion, and environment handling |

The integrated shell supports built-ins including `echo`, `pwd`, `cd`, and `export`. Nano introduces redirection operators such as `<`, `>`, and `2>`; Micro combines those features with shell state.

## My contribution

I implemented the utility collection and the Femto-to-Micro shell progression as a solo project. The work applies C system calls and process-management concepts to command execution, file operations, redirection, and environment handling.

## Operating-system concepts

Some commands must change the shell process itself: for example, changing a child process's working directory does not change its parent's directory. Redirection operates on file descriptors, while variable assignment and export distinguish shell-local state from values inherited by executed programs.

These are the central design responsibilities explored by the project. The staged structure makes it possible to inspect how each feature changes the command-processing loop.

## Scope and evaluation

This is an educational shell implementation. The repository documents compilation and usage examples, but does not establish POSIX-shell conformance or publish a comprehensive compatibility test suite.

[Read the staged shell article](/blog/building-a-unix-shell-in-stages/) for a deeper explanation of parsing, processes, descriptors, and environment handling.
