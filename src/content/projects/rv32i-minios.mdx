## From CPU design to operating systems

This ongoing computer-engineering project connects a RISC-V RV32I CPU design with the foundations needed to build a small operating system. The CPU implementation and the miniOS work are at different stages.

## Completed CPU work

I completed CPU implementations in Logisim and Verilog. RTL components include the program counter, control unit, ALU decoder, and instruction memory, alongside assembly and hexadecimal test programs.

This work connects instruction execution and datapath control with concrete hardware implementations.

## miniOS: ongoing

I am studying CPU scheduling concepts and algorithms in preparation for implementing a miniOS on the RISC-V design. The miniOS is ongoing work; a functioning kernel or scheduler implementation is not yet documented in the available project information.

## Next steps

The next stage is to connect the scheduling study to the CPU design, define the miniOS execution requirements, and document the implementation and validation as it develops.
